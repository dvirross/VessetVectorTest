# External replication — Utah Creighton Model cohort

Self-contained replication of the manuscript's analysis on an independent, openly deposited dataset
(Stanford & Najmabadi 2023, *Menstrual Cycles Length of Women in the USA and Canada, 1990–2013*,
The Hive, University of Utah, https://doi.org/10.7278/S50d-4gxs-s4hj, CC BY-NC). Nothing outside this
folder is written by the code here; counting rules are imported from `../scripts/patterns.py`.

Reproduce (from the repository root, ~30 min on 3 cores):

```bash
python external_replication/scripts/prepare_utah.py            # raw -> data/sequences.csv
python external_replication/scripts/run_external.py --nproc 3  # -> results/
python external_replication/scripts/all_runs_sensitivity.py    # ~5 min: run-selection sensitivity -> results/all_runs_sensitivity.json (SI Table S8)
python external_replication/scripts/preprocessing_sensitivity.py  # ~9 min: twelve preprocessing specifications -> results/preprocessing_sensitivity.json
python external_replication/scripts/build_replication_notebook.py
(cd external_replication/notebooks && jupyter nbconvert --to notebook --execute --inplace replication.ipynb)   # ~3 min
```

The SI S7 and S8 scripts live in the repository root (`scripts/directional_ordering.py`,
`scripts/heterogeneity_benchmark.py`, `scripts/independent_check.py`) and analyse both cohorts; their Utah
outputs are `results/directional_ordering_utah.json` and the Utah entries of `results/heterogeneity_benchmark.json`
and `results/independent_check.json` at the repository root. The notebook here displays them and recomputes S7.
